Added `clientAssertion` to the `SecurityPolicy` OIDC configuration, which authenticates the OIDC client to the token endpoint with a Kubernetes ServiceAccount token sent as a JWT client assertion instead of a client secret. Envoy Gateway requests the token for the referenced ServiceAccount with the TokenRequest API and renews it before it expires. The owner of the `SecurityPolicy` grants `create` on `serviceaccounts/token` for the ServiceAccount to the Envoy Gateway ServiceAccount, and the Envoy Gateway installation grants no new permissions. This requires an Envoy version that supports the `CLIENT_ASSERTION` authentication type of the OAuth2 filter.
