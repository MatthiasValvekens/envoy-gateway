Changed the Go type of `OIDC.ClientSecret` in `api/v1alpha1` from `gwapiv1.SecretObjectReference` to `*gwapiv1.SecretObjectReference`, and made `clientSecret` optional in the `SecurityPolicy` CRD, because `clientAssertion` is the alternative. A CEL rule requires exactly one of the two. Existing `SecurityPolicy` objects remain valid, but Go code that reads `OIDC.ClientSecret` must check it for nil.
